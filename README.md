# QQ 聊天记录导出工具

从本地 NTQQ 解密数据库(`nt_msg_decrypted.db`)提取 QQ 私聊记录为纯文本的工具。

> 2026-08-14 拆分说明:本项目原包含小说创作内容,现按"工具 / 创作"拆分为两个独立项目。所有聊天记录数据与创作素材已移至 [[小说-永不相见]](`Projects\小说-永不相见`),本目录只保留工具本身。

## 功能

- 连接 `c2c_msg_table` 私聊表,提取全部联系人或指定 QQ 的聊天记录
- 纯中文文本清洗(过滤 rkey/appid 等底层乱码标记)
- 支持时间范围过滤、自定义昵称命名
- 自动按 QQ 号命名导出,每个联系人一个 `.txt`

## 用法

```powershell
python extract.py
```

交互式选择:
1. 提取所有人(自动用 QQ 号命名)
2. 提取指定人(可自定义昵称命名)

## 路径配置

`extract.py` 顶部配置区:

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DB_PATH` | `C:\Users\27731\Desktop\nt_msg_decrypted.db` | NTQQ 解密数据库 |
| `EXPORT_DIR` | `C:\Users\27731\Desktop\QQ聊天记录导出` | 导出输出目录 |

## 注意事项

- 数据库为个人隐私数据,不在本仓库保存
- 导出的聊天记录属隐私,仅作个人用途;用于创作时需化名处理(见小说项目规范)
